## Before building

A GitHub-first search found useful neighbors at three different layers.
[AgenticBooks](https://github.com/AgenticBooks/agenticbooks-mcp) exposes private
operating books through an authenticated connector.
[Pinch](https://github.com/thecraighewitt/pinch) keeps wallet policy and transaction
history beside an agent. [Accounting Ops
Community](https://github.com/Unicorn-Commander/accounting-ops-community) provides a
full self-hosted ledger with reconciliation and reports.

None is the small public disclosure handoff this job needs. Open Agent Books does not
replace them. It gives an outsider one predictable file whose money claims can be
followed to evidence. The smallest useful build was therefore a public explanation
of the existing schema, not a new accounting system.

The acceptance contract is an `oab.html` page linked from the home page and primary
navigation, plus a fetchable copy of the schema. The page must explain the boundary
between a transfer and its claimed business meaning, and it must name the existing
tools it sits beside. A missing page, dead schema link, or failing site build disproves
the work.
